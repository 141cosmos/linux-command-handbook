# Linux Command Handbook

A beginner-friendly guide to Linux commands with simple explanations and practical examples.

---

## 1. `pwd` — Print Working Directory

**Purpose:** Shows the directory you are currently in.

**Example:**

```bash
pwd
```

**What it does:** Displays the full path of your current directory.

---

## 2. `ls` — List Files

**Purpose:** Shows files and folders in the current directory.

**Example:**

```bash
ls
```

**What it does:** Lists the files and folders inside the current directory.

---

## 3. `cd` — Change Directory

**Purpose:** Moves you to another directory.

**Example:**

```bash
cd Documents
```

**What it does:** Takes you into the `Documents` directory, if it exists in your current location.

---

## 4. `mkdir` — Make Directory

**Purpose:** Creates a new directory (folder).

**Example:**

```bash
mkdir practice
```

**What it does:** Creates a new folder named `practice` in the current directory.

---

## 5. `cat` — Display File Contents

**Purpose:** Displays the contents of a text file.

**Example:**

```bash
cat notes.txt
```

**What it does:** Prints the contents of `notes.txt` in the terminal, if the file exists.

---

## What I Learned

- How to check my current directory.
- How to list files and folders.
- How to navigate between directories.
- How to create new directories.
- How to view the contents of text files.
